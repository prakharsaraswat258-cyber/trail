# Penga — Unified Lost & Found Feed

A Next.js 14 + TypeScript + Tailwind CSS application featuring a unified Lost & Found match engine for community reports.

## Features
- **Global Sticky Header**: Penga geometric dragon logo, Report Lost (`/lost`) & Report Found (`/found`) CTAs, notification bell with unread badge and dropdown preview.
- **Stats Strip**: Compact Bento chips displaying items returned, active reports, and average time to match.
- **Sticky Search & Category Bar**: 400ms debounced search, segmented type toggle (All/Lost/Found), category dropdown, and quick-browse category tiles with synchronized scroll.
- **Unified Feed**: Centered single-column stream combining Lost and Found reports with 3-tier algorithm confidence badges, photo/placeholder fallbacks, and cursor infinite scroll.
- **Brand System**: Built strictly adhering to the Light Theme Brand DNA tokens (Canvas `#FAF8F3`, Surface `#FFFFFF`, Accent `#C96442`).

## Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
